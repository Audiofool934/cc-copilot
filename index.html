A few useful details.

        

          

            
              Does it change what my agent is doing?+
            
            

              CC-Copilot reads the working session without editing its
              transcript or injecting prompts. The local Claude and Codex
              narrator backends are read-only by default. You can explicitly opt
              out of that narrator confinement in configuration.
              See the full boundaries.
            

          

          

            
              Do I need another API key?+
            
            

              Not when you use your existing Claude Code or Codex login. You can
              also use an API provider or a local Ollama model. Deterministic
              commands such as brief, check, and
              observe need no model at all.
            

          

          

            
              Can I follow more than one session?+
            
            

              Yes. Use /sessions to select sessions, or
              @project for project-level evidence. Claude Code,
              Codex, and Grok Build sessions can appear on the same project
              board.
            

          

          

            
              What context is sent to a model?+
            
            

              Model-backed answers receive bounded evidence, including
              transcript excerpts, tool results, project facts, and cockpit
              history. Secret-shaped content is scrubbed from the model-bound
              copy. The original local transcript stays unchanged.
              Read about evidence context.
